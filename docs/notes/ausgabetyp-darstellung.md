# Darstellung der Ausgabetypen

> Jeder Wert trägt Farbe und Icon seines `NodeOutputType`; welcher Typ zu welchem Baustein gehört, steht nur in `workflow_output_types.dart`.

Gehört zu: [Aufgabe](../index/aufgabe.md)

- Stil: `NodeOutputTypeStyle`, Farben in `OutputTypeColors`.
- Typen: `string`, `datetime`, `number`, `boolean`, `json`, `file`, `media`,
  `audio`, `table`. `audio` z. B. mit Lautsprecher-Symbol.
- `workflow_output_types.dart` spiegelt die Tabelle
  [Registrierte Executor-Outputs](./executor-outputs.md).
