# Transformation `tensor.round`

> Rundet Werte auf eine feste Zahl von Nachkommastellen.

Gehört zu: [Transformationen](../index/transformationen.md)

**Wertart:** `tensor` → `tensor`

## Parameter

| Parameter | Wert | Pflicht | Standard |
| --- | --- | --- | --- |
| `decimals` | ganze Zahl ≥ 0 | nein | `0` |

Hinweis: optional `decimals` (Standard `0`)
