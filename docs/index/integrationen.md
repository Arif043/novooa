## Offene Punkte

- Shopware gegen einen echten Shop prüfen (API-Formen, App ohne `<setup>`,
  Nutzlast der Webhooks).
- Signierte App-Aufrufe, Dokumente, Sprachwahl, Anlegen von Datensätzen.
- Der KI-Agent kennt die Shopware-Bausteine nicht.
- `EventTriggerSource` im Client für Plugins öffnen.
