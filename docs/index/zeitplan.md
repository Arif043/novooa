# Zeitplan

> Zeit- und ereignisgesteuerte Auslöser legen fest, **wann** eine Aufgabe läuft, ohne den Workflow selbst zu ändern.

Umgesetzt sind zeitbasierte Auslöser sowie Ereignis-Auslöser für Dateien,
Webhooks und E-Mails.
